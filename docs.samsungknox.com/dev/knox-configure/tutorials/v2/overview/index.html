Overview

Last updated October 8th, 2026

This document is new for the Knox cloud services 26.10 UAT.

Knox Configure is a cloud-based service that enables enterprises to remotely provision and configure Samsung devices through REST APIs. With Knox Configure, you can automate device setup, manage configuration profiles, and deploy settings at scale across your device fleet.

You can use the Knox Configure v2 API to manage devices, profiles, licenses, applications, and content programmatically. The tutorials in this section cover various use cases of the Knox Configure v2 API.

The following table shows Knox Configure v2 API offerings:

Category Knox Configure action Required scope
Manage devices Retrieve devices kc.devices:view
Retrieve device logs kc.devices:view
Send a command to devices kc.devices:manage
Delete devices kc.devices:manage
Manage profiles Create a profile kc.profile:manage
Retrieve profiles kc.profile:view
Retrieve profile details kc.profile:view
Delete a profile kc.profile:manage
Assign and push profiles Assign a profile to devices kc.profile:assign
Unassign a profile from devices kc.profile:assign
Push profile updates kc.profile:manage
Custom notifications Create a custom push notification kc.profile:manage
Retrieve custom push notifications kc.profile:view
Manage licenses Retrieve licenses kc.license:view
Retrieve license details kc.license:view
Register a license kc.license:manage
Delete a license kc.license:manage
Manage applications Retrieve applications kc.application:view
Retrieve application details kc.application:view
Upload a public application kc.application:manage
Upload an in-house application kc.application:manage
Generate an application download URL kc.application:manage
Delete applications kc.application:manage
Manage content Upload content files kc.content:manage
Generate a content download URL kc.content:manage
Delete content files kc.content:manage
