Device and Settings customization profile

Last updated September 4th, 2026

With Knox Service Plugin, you can customize a variety of device settings and UI elements through the Device and Settings customization profile (Premium), including the Samsung keyboard, Quick Panel shortcuts, device naming, app suggestions, battery behavior, lockscreen shortcuts, and audio volume.

The Device and Settings customization profile (Premium) is available with a free Knox Platform for Enterprise Premium license.

  1. On your EMM console, add an assignment for the Knox Service Plugin app intended for your target devices, or edit it if one already exists.

  2. On the Knox Service Plugin managed configuration, set Device-wide policies > Device customization controls (Premium) to True.

Now you’re ready to configure the policies below under Device and Settings customization profile (Premium).

Device name

To find these policies, go to Device and Settings customization profile (Premium) > Enable Device Name in Settings.

  • Enter a Set Device Name value to specify the device name.

  • Set Allow Device Name Change by End User to True to permit device users to change the device name. Set to False to prevent device users from changing it.

Samsung keyboard controls

To find these policies, go to Device and Settings customization profile (Premium) > Samsung keyboard controls.

  • Use Disable Predictive text to enable or disable predictive text based upon the words being typed. This can be useful when the words or the language being typed is not in English.

  • Set Disable Keyboard settings to True to prevent the device user from accessing Samsung Keyboard settings.

  • Refer to Samsung Keyboard Toolbar Controls to enable or disable the following toolbar items:

    • Disable Emoticon
    • Disable Grammarly (Only available on devices running One UI 6.1.1 or later)
    • Disable Sticker
    • Disable GIF Keyboard
    • Disable Voice Input
    • Disable Live Message
    • Disable Handwriting Input
    • Disable Clipboard
    • Disable Modes
    • Disable Text Edit Panel
    • Disable Search
    • Disable Spotify
    • Disable YouTube
    • Disable AdjustSize
    • Disable AR Emoji
    • Disable Bitmoji
    • Disable Expression
    • Disable Mojitok
    • Disable Samsung Pass
    • Disable Translation

Quick Panel configuration

To find these policies, go to Device and Settings customization profile (Premium) > Quick Panel configuration.

  • Refer to the Items on Quick Panel control to show one or more items <bundle> from the list of shortcuts available in the quick settings panel. Each of the following controls utilizes an enable (True) or disable (False) parameter:

    • Set the Show airplane mode control to True to display a shortcut to the airplane mode control on the quick settings panel.
    • Set the Show screen rotation control to True to display a shortcut to the screen rotation control for display orientation on the quick settings panel.
    • Set the Show always-on screen control to True to display a shortcut to the always-on screen control on the quick settings panel. Keep in mind, enabling this setting consumes additional battery power.
    • Set the Show Bluetooth control to True to display a shortcut to the Bluetooth control on the quick settings panel.
    • Set the Show Samsung DeX control to True to display a shortcut to the Samsung DeX control on quick settings panel.
    • Set the Show mobile hotspot control to True to display a shortcut to the mobile hotspot control on the quick settings panel.
    • Set the Show NFC control to True to display a shortcut to the NFC control on the quick settings panel.
    • Set the Show background sync control to True to display a shortcut to the background data sync control for fresh content updates on the quick settings panel.
    • Set the Show Wi-Fi control to True to display a shortcut to the Wi-Fi control on the quick settings panel.
    • Set the Show Location control to True to display a shortcut to the location control on the quick settings panel.
    • Set the Show Screen Mirroring control to True to display a shortcut to the screen mirroring control on the quick settings panel.
    • Set the Show Do Not Disturb control to True to display a shortcut to the do not disturb control for notifications on the quick settings panel.
    • Set the Show Dolby control to True to display a shortcut to the Dolby control for interactive sound enhancement on the quick settings panel.

  • Use the Allow user to edit Quick Panel control to either allow (True) or block (False) the device user from editing the configuration of the quick settings panel.

App suggestions

To find this policy, go to Device and Settings customization profile (Premium) > Disable app suggestions.

  • Use the Disable app suggestions control to disable application suggestions in the task manager and other locations. This control is only available to Knox 3.4 and above supported devices.

Battery

To find these policies, go to Device and Settings customization profile (Premium).

  • Set the Enable battery protection setting control to True to enable the protect battery setting to stop the device from charging before it reaches 100% charge. This setting does not take effect until the next time the device is booted. This control is only available to Knox 3.4 and above supported devices.

  • Use the Set the battery charging configuration control to set minimum and maximum threshold values for battery charging start and stop points. This feature helps extend battery lifespan by preventing overcharging.

    • Start battery charging level — Battery percentage at which charging starts (minimum value: 10).
    • Stop battery charging level — Battery percentage at which charging stops (maximum value: 90).

Lockscreen customization

To find these policies, go to Device and Settings customization profile (Premium) > Lockscreen customization.

  • Use the Lockscreen shortcuts control to enable the utilization of device lockscreen shortcuts. This control must be enabled before app shortcut customizations are permitted.

    • Enter an App for left shortcut package name <string> to specify the app that opens when the device user utilizes the left shortcut on the device lockscreen.

    • Enter an App for right shortcut package name <string> to specify the app that opens when the device user utilizes the right shortcut on the device lockscreen.

There are additional deep settings available for the lock screen, including configuration parameters for the roaming clock, face widgets, notifications, language and input, system sounds and vibrations, display settings, and font usage. These features are available with a free Knox Platform for Enterprise Premium license on devices running Knox version 3.4 or later. To learn more, see Deep Settings Customization.

Configure values in settings menu

To find these policies, go to Device and Settings customization profile (Premium) > Configure values in settings menu.

This group of policies lets you configure values for a wide range of individual device settings, spanning categories such as accessibility, apps, connections, display, font size and style, general management, location, notifications, sounds and vibration, and Wi-Fi. For each setting, you can specify a value, and choose whether to hide the setting or prevent the device user from modifying it. Support for individual settings varies based on the device model and OS version.

Because of the wide range of configurable settings, this feature has its own dedicated page. For the full list of configurable settings and how to set them, see Deep Settings Customization.

Audio volume

To find these policies, go to Device and Settings customization profile (Premium) > Audio Volume Controls.

  • Use Audio Volume Controls to set the volume level for a specific audio stream. Configure the following fields:

    • Audio Stream — Select the audio stream to configure. Options: Ringer, Voice Call, System Sounds, Media Playback, Notifications.
    • Volume Level — Specify the volume level for the selected audio stream. Maximum value is 15. For Voice Call, the range is 1 to 8.
