Knox Admin Portal 26.10 release notes

Last updated October 8th, 2026

This document is new for the Knox cloud services 26.10 UAT.

On this tab

  • New
  • New Users page to manage workforce users (Labs)
  • Enroll devices through user sign-in
  • New common role permissions
  • Updates
  • Enterprise Edition security updates in Security dashboard
  • Download on-premises apps from the dashboard
  • Improved session time management across multiple tabs

New

New Users page to manage workforce users (Labs)

Previously, if you used Samsung account for Business as your sign-in method, you had to navigate to the Samsung account for Business console to manage the workforce users in your service location.

With this release, the new Users page brings workforce users (that is, employee accounts) into the Knox Admin Portal, expanding user management beyond just admins.

From the Users page, you can now view users and edit their details, invite and delete users, resend activation links to users, and sync users with Samsung account for Business. You can also assign enrollment profiles to users, letting them enroll devices simply by signing in to devices.

Note that these users are not the same as Knox Manage users shown in the Knox Manage console. However, if a Knox Manage user is also a workforce user in your service location, they are shown on the Users page as well.

For more information on how you can manage users, see Manage users.

Enroll devices through user sign-in

Previously, you could assign enrollment profiles to devices to enroll them into Knox cloud services. If configured in reseller preferences, the enrollment profiles were automatically applied to devices added and approved in the Knox Admin Portal.

With this release, you can now assign enrollment profiles to users from the Users page, such that when they sign in to a device, the enrollment profile is applied and the device is enrolled. You can also view the number of devices that are enrolled by user account.

This user account-based enrollment is available only if your company’s Knox account is linked to Samsung account for Business, the admin has the new Assign and unassign enrollment profiles permission, and the feature is enabled in Settings using the Enroll devices in Knox services during sign-in toggle.

For more information, see Assign an enrollment profile and Unassign an enrollment profile.

New common role permissions

With this release, super admins can now assign the following new Common permissions to custom sub-admin roles:

New common permission Permitted actions

Users > View-only

For Samsung account for Business only.

View the Users menu and the list of users you manage.

Users > Manage users > Create and edit

For Samsung account for Business only.

Add users and edit user details on the Users page.

Users > Manage users > Assign/Unassign enrollment profile

For Samsung account for Business only.

Assign and unassign enrollment profiles to users on the Users page.

Users > Manage users > Delete

For Samsung account for Business only.

Delete users on the Users page.
Support tickets > View only admin's own tickets View and manage only the support tickets created by the sub-admin.
Support tickets > View all tickets within the same Knox tenant View and manage all support tickets associated with the Knox company account.

For more information about available common roles, see Manage roles.

Updates

Enterprise Edition security updates in Security dashboard

Previously, security details related to Enterprise Edition devices were available on the SECURITY UPDATES tab of the Enterprise Edition dashboard.

With this release, the centralized common Security dashboard also includes security updates for Enterprise Edition devices, along with security, vulnerability, and integrity insights for your other devices. As a result, the SECURITY UPDATES tab on the Enterprise Edition dashboard now redirects you to the Security dashboard.

Download on-premises apps from the dashboard

Previously, there was no direct way to download the Knox Service Plugin and Knox Native Solution apps for on-premises Knox service deployments.

With this release, you can easily download the Knox Service Plugin and Knox Native Solution apps directly from the Other solutions and tools tile on the Knox Admin Portal dashboard.

Improved session time management across multiple tabs

Previously, if the Knox Admin Portal was open in multiple browser tabs, the session times were not synchronized across the tabs. As each tab could have a different session expiration time, you could be signed out unexpectedly.

To prevent unexpected interruptions and provide a more consistent experience, session times are now synchronized across open tabs. All tabs display the longest remaining session time from the tab opened last. For example, if you open three tabs, the session time in the first and second tabs is updated to match the session time of the third tab.

If you have less than five minutes of session time left, a Session timeout pop-up appears and lets you extend your session. If your session expires, a Session expired pop-up appears and prompts you to sign in again.
