Overview

Last updated October 21st, 2026

Users is a Labs feature. Labs features are experimental and may be modified or discontinued without prior notice.

If you use Samsung account for Business as your sign-in method, the Users page is shown to you in the Knox Admin Portal. The Users page provides a centralized view of all users associated with your Knox company location.

From the Users page, you can manage users, that is, employee accounts, without navigating to the Samsung account for Business console. You can view user information, add and manage users, assign or unassign enrollment profiles, and view the devices associated with users.

User information sync

User information between the Knox Admin Portal and the Samsung account for Business console is automatically synced to keep the user list up-to-date.

When you access the Users page for the first time, a message prompts you to start the initial sync, which can take some time to complete. You can leave the page while the sync is in progress, and you’ll be notified when it’s complete.

After the initial sync, new and modified users are automatically synchronized for you. All synchronization updates are captured in the activity log.

Users list

The users list shows employee accounts from the Samsung account for Business console. It lists only the users associated with the Knox company account you manage. Accounts with admin privileges display the Knox admin tag next to their name.

The users displayed on the Users page are not the same as the users shown in the Knox Manage console. If you see any Knox Manage users on the Users page, it’s because they’re also registered and associated with your Samsung account for Business.

The user list displays the following information:

Column Description
Name Name of the user. Click a name to open a sliding panel with detailed user information and make edits, if required.

Accounts with admin privileges for Knox cloud services show the Knox admin tag next to their name.
Account ID Account ID of the user.
Account status Current account status of the user.
Work email Work email address of the user.
Enrollment profile Enrollment profile assigned to the user. Click an enrollment profile to view the assigned profile.
Signed in device Number of registered devices associated with the user. Click the device count to open the Devices page filtered for the selected user.
Department Department associated with the user.
Division Division associated with the user.
Source type Method used to add the user.
Authentication type Authentication type associated with the user.
Last synced Last synchronization date and time for the user.

Search and filter users

You can use the search bar on the Users page to quickly find users and can use filters to narrow down the search results.

Search for users

To search for a user, type their exact full name (first name, last name, or both), account ID, or work email in the search bar. You can only search one user at a time.

Filter search results

To narrow the users displayed in the search results, filter them using the following columns:

  • Division
  • Department
  • Account status
  • Enrollment profile
  • Source type
  • Authentication type

You can also sort the users by the Last synced column.

View user details

Click a user name to open a sliding panel that shows detailed information about the user.

The sliding panel includes information about up to four devices that the user is signed into. In case the number of signed-in devices is more than four, click Show all devices to open and view the complete list sorted by user on the Devices page.
