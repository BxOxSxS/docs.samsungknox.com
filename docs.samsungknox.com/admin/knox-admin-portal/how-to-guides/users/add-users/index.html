Add users

Last updated September 16th, 2026

This document is new for the Knox cloud services 26.10 UAT.

On this tab

  • Invite a user manually
  • Add users from Samsung account for Business

Users is a Labs feature. Labs features are experimental and may be modified or discontinued without prior notice.

You can add users to the Users page by creating a user manually or by adding existing users from Samsung account for Business.

Invite a user manually

When you invite a user from the Users page, the user information is synced with the Samsung account for Business console and the user is added as a Workforce user under your service location.

To add a user manually:

  1. On the Users page, click Add users > Invite a user. The Invite user page displays.

  2. Enter the following user information:

    • First Name
    • Middle Name (optional)
    • Last Name
    • Work Email

  3. To set the user’s Account ID, which is a combination of their user ID and company’s domain, enter the following:

    • User ID
    • Domain: Select from the drop-down.

  4. (Optional) Enter the following information:

    • Division
    • Department

  5. Click Invite user.

The user information is checked for duplicates, and if no duplicate is found, the user is invited and a success message displays. The user is also created in Samsung account for Business under your service location with the Workforce role.

All updates related to creating the user are captured in the activity log.

Add users from Samsung account for Business

If you manage multiple locations in the Samsung account for Business console as a Location Manager, you can add users from other locations not associated with your Knox company account. After the next sync, the added users are then shown on the Users page in the Knox Admin Portal.

You can add users to your service location directly from the Users page, without navigating to the Samsung account for Business console. In the Knox Admin Portal:

  1. On the Users page, click Add users > Add users from Samsung account for Business. The Add users from Samsung account for Business page displays a list of users from other locations, which do not exist in your current service location.

  2. Select the users you want to add to your current service location. You can search users by their name, account ID, or work email, and sort the user list by name, work email, and status.

    If you can’t find a user on the Add users from Samsung account for Business page, it may be due to one of the following reasons:

    • The user doesn’t exist in the service location you manage or any other locations associated with your company.
    • In Samsung account for Business console, you don’t have the required permissions to access users from other locations.

  3. Click Review users. These users will be added to your current service location and will appear on the Users page.

  4. Click Add users.

The selected users are added to the users list. All updates related to adding the users are captured in the activity log.
