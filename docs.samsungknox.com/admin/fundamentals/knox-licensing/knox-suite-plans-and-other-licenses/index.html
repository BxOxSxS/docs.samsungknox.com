Knox Suite Plans and other licenses

Last updated September 21st, 2026

Knox Suite Plans combine multiple Knox cloud services under a single license. If you need only a specific service, a standalone license may be available.

Use the following table to compare the services included in each Knox Suite Plan, check whether a standalone license is available, and see the available trial and commercial licensing options.

Knox service Usage Free trial licenses Commercial licenses
Knox Suite - Enterprise Plan Standalone trial license Knox Suite - Base Plan Knox Suite - Essentials Plan Knox Suite - Enterprise Plan Standalone license

Knox Platform for Enterprise (Knox Service Plugin) Device Yes Yes Yes Yes
Knox Platform for Enterprise DualDAR (Knox Service Plugin) Device Yes

The following Knox services are free to use, but you may still need to generate a license to use them.

  • Knox Mobile Enrollment: No license required.
  • Knox Mobile Enrollment Direct: Requires a free, on-premises Knox Mobile Enrollment Direct license. You can generate one from the Knox Mobile Enrollment Direct download page.
  • Knox Platform for Enterprise (Knox Service Plugin): Requires a free, device-based Knox Platform for Enterprise Premium license. You can activate this license through your EMM.
